# Review System

React review interface exercise with a dedicated review component and stylesheet.

## Project structure

- `src/components/Reviews.jsx`
- `src/components/review.css`
- `src/App.jsx`

## Getting started

Install Node.js and npm, then run:

```bash
git clone https://github.com/JAYANTI-THAKOR-941/review-system.git
cd review-system
npm install
npm run dev
```

Open the development URL displayed in the terminal.
